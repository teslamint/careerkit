# Test Inventory

U0 collected-test baseline for the former pytest layout. Every collected module
under `templates/tests/` appears exactly once with its intended top-level
destination family.

- Baseline collected module count: 82
- Baseline proof: the combined pre-cutover suite passed before deletion.
- Final disposition: all 82 legacy modules were reviewed and deleted after the
  migrated package suite, static gates, and legacy-free clean candidate passed.
- `proposed_destination` records the original migration target. Consolidation
  intentionally produced fewer, behavior-oriented modules rather than 82
  one-for-one file renames.

## Final replacement coverage

| Legacy concern | Final blocking coverage |
| --- | --- |
| Resume build, schema, notes, verification, and rendering | `tests/resume/` |
| JD application, screening, status, and automation | `tests/jobs/application/`, `tests/jobs/test_*.py` |
| Platform extraction and HTTP contracts | `tests/jobs/platforms/` |
| Canonical storage and migration | `tests/jobs/storage/` |
| Web console | `tests/jobs/console/` |
| Entrypoints, package privacy, hooks, and migration boundaries | `tests/architecture/`, `tests/contract/` |

The disposition gate requires this baseline count, the reviewed-deletion marker,
the absence of the former test root, and collected tests in every final coverage
family. A new final family must update both this table and the gate.
